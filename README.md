# Honeycomb-Clicker
A 3D CAD model of a magnetic fidget clicker with hexagonal designs all around the model. The inspiration for this model came from my wish to use magnets on my first ever CAD fidget. I searched online for examples, and came across other clickers, who used protruding parts to create a click. However, I was curious on how a magnet will feel, so I decided to recreate the classic clicker fidget with magnets instead. On the way, I also decided to add some flare with hexagonal cutouts. Here, I currently have the Honeycomb v3.6 clickers, with 2x4 and 2x5 mm magnet sizes.
